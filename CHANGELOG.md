# Changelog

All notable changes to Android Devtools are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-11-16

### Added

- Orca panel for detecting Android projects, selecting devices and build variants, and running build/install/launch workflows.
- Per-project panel preferences and cached project discovery with an explicit Refresh action.
- YAML profile management for launch options and typed Android Intent extras.
- Build and run logs with copy, send-to-agent, show/hide, and clear controls.
- Orca command and standalone CLI using the shared Android resolver and runner.
- Marketplace icon, generated cover artwork, an Orca panel capture, and illustrative Profile manager and Logs mockups.
